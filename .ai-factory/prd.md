# CertTimer

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
자격증 시험 D-day·학습 진도 트래커 — 매일 체크인하면 배너 광고, 합격 예측 리포트는 리워드 광고 후 공개

## Problem
자격증 준비생은 시험 일정·학습량을 분산된 앱·메모장에 기록하며 동기부여를 유지하기 어려움. 하루 공부량 추적과 남은 일수 가시화 도구가 토스 생태계에 없음

## Target Users
공인중개사·한국사·컴활·SQLD·토익 등 자격증 준비 중인 20-40대 직장인·취준생 (연간 응시자 300만+)

## Core Features
1. 자격증 시험 데이터베이스 (주요 50종 시험일 내장) + 커스텀 등록
2. 오늘 공부 시간 체크인 (스탑워치 or 수동 입력) + 연속 체크인 스트릭
3. D-day 기준 일일 목표 학습량 자동 계산 및 달성률 시각화
4. 배너 광고: 체크인 완료 화면 하단 노출
5. 리워드 광고 시청 후 '합격 가능성 예측 리포트' (누적 학습량 기반) 공개
6. 시험별 기출 키워드 퀴즈 1일 3문제 (localStorage 오답 저장)

## Monetization
- Model: ads
- Estimated MRR: 6800000
- Reasoning: 일일 체크인 메커니즘으로 DAU 유지 핵심. DAU 5,000 목표. 리워드(합격 예측, 전환율 25%): 5,000×0.25×30×4/1000×1350×0.85 = 약 515만 원. 배너: 5,000×2×30×1/1000×1350×0.85 = 약 344만 원. 합계 약 859만 원 → 15% 수수료 후 순수익 약 730만 원. 단 DAU 5,000은 낙관적이므로 보수적 3,000 기준 약 440만 원.
